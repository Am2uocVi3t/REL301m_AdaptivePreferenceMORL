# Structured Paper Notes

Create notes through `python scripts/research_harness.py paper add ...`. A paper may be marked `read` only after verified full-text access and after its note covers mechanism, assumptions, protocol, relationship to project claims, and limitations. Metadata or abstract-only access remains `screened` and must include `FULL_TEXT_REQUIRED`; the agent reports the blocker and asks the user for an uploaded PDF or authorized link. PDFs remain outside Git.
