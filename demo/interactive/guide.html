MORL Preference Lab

Inference demonstration guide

Both panels use the same frozen policy and initial seed. Sliders change preference inputs, never model weights. No training or paid API is involved.

  1. Select LunarLander or Minecart. The environment starts paused.
  2. Select Single step to inspect one real transition.
  3. Adjust preference weights. Changes are pending until Run comparison resets both panels with matched initial seeds.
  4. Use Pause, Resume and speed controls to inspect behavior.
  5. Live preference changes apply at the next step and retain history. Reset to restore a matched-initial-state comparison.
  6. Native renderer shows original environment graphics. Download trace JSON to inspect actions and rewards.

Read results carefully

Raw returns are not success percentages. Cost components are negative rewards. More weight on a cost means greater importance on avoiding it. Different preferences need not produce different behavior in every state.

Minecart uses the lowest confirmation training seed, 20264311. Lunar uses specialist pilot 20265311; two separate prospective confirmation seeds appear in the report. Neither demo guarantees every preference, dynamics robustness or adaptive-allocation superiority.

Errors and privacy

Use one controlling tab. Failed physics requests are not retried automatically. Reset or reload to recover. Keep the server bound to localhost; Ctrl+C stops it.
