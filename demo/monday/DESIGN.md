# Local evidence explorer

An offline research presentation, not a marketing site or live agent console.
Retain the report's FPT orange (#e1723a), dark ink (#172b36), white background,
teal evidence accents (#23767d), 8px radius and system sans-serif. Use clear
tables rather than decorative charts for zero counts. Real and synthetic data
occupy separate sections. All controls have visible labels and keyboard focus.
One-column layout below 760px; reduced-motion users receive no animated scroll.
No network assets, telemetry, API calls, training buttons or external scripts.
